# tiny-chess-01 entry

A chess engine in at most 4,096 bytes of Python (main.py, packed with the kit compress command from engine_src.py). Negamax alpha-beta with transposition table, quiescence, null-move pruning and piece-square evaluation. MIT, see LICENSE.
